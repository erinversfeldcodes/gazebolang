# Security

## Reporting a vulnerability

Please report a vulnerability privately, to https://github.com/erinversfeldcodes/gazebolang/security/advisories/new. Do not open a public
issue for it.

Your report is visible only to you and the maintainer.

## Response

The maintainer will acknowledge a report within 5 business days and aim to give
a fix or mitigation timeline within 30 days for a confirmed vulnerability. Once
a fix is out, the advisory is published with credit to you.

## Supported versions

Only the latest release, or the latest commit on the default branch where there
are no releases, is supported.
